# Super-store-Excel-dashboard
# 📊 Superstore Sales Analysis Dashboard | Excel

## 📌 Project Overview
This project showcases an **interactive Sales Analysis Dashboard built in Microsoft Excel** using the **Superstore dataset**.  
The dashboard provides insights into **sales, profit, discount behavior, customer performance, regional trends, and product categories**, enabling data-driven business decisions.

---

## 🎯 Project Objectives
- Analyze overall **sales and profit performance**
- Identify **top-performing regions and product categories**
- Understand the **impact of discounts on profit**
- Compare performance across **segments and years**
- Build an interactive, business-ready Excel dashboard

---

## 📈 Key Performance Indicators (KPIs)
- **Total Sales:** 229,7200.86  
- **Total Profit:** 286,397.02  
- **Average Discount:** 0.156  
- **Top Region:** West  
- **Top Category:** Technology  

---

## 📊 Dashboard Insights

### 🌍 Regional Performance
- **West** region leads in overall sales and profit
- Regional slicers allow comparison across Central, East, South, and West

### 🧩 Category Analysis
- Categories analyzed:
  - Furniture  
  - Office Supplies  
  - Technology  
- **Technology** contributes the highest sales and profit

### 💰 Discount vs Profit Analysis
- Scatter plot highlights the **negative impact of high discounts on profit**
- Helps identify loss-making discount ranges

### 👥 Customer Performance
- Top customers ranked by total sales
- Identifies high-value customers for targeted strategies

### 📅 Time-Series Trends
- Monthly sales trends reveal seasonality
- Year filter enables analysis from **2014–2017**

### 🧱 Segment Analysis
- Consumer  
- Corporate  
- Home Office
